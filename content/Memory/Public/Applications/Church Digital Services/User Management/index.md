# User Management System

Internal Next.js admin panel for managing Emmanuel Ministries Hyderabad church members and operations.

## 🔐 Access
**Internal Use Only** - Authorized staff and admins

## ✨ Features Built

### 👥 Member Management
- View all church members
- Add new members
- Edit member details
- Family linking (HOF - Head of Family)
- Search and filter members
- Phone number management

### ✅ Attendance Tracking
- Weekly attendance marking
- Attendance history view
- Family-wise attendance
- Generate attendance reports

### 📊 Reports & Analytics
- Weekly attendance summaries
- Total membership counts
- Attendance percentage
- Export to Excel/PDF

### 🔒 Admin Functions
- Secure login system
- Role-based access (Admin/Staff)
- Activity logging

## 🛠 Technical Details
- **Framework**: Next.js 16.2.0
- **Language**: TypeScript
- **UI**: Radix UI + Tailwind CSS v4
- **Database**: MongoDB via API
