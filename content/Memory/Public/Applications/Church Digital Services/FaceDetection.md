# Face Detection Attendance System

Integrated face detection system for Emmanuel Ministries Hyderabad - built in collaboration with **ESSL India** (a leading security solutions company).

## 🎯 Purpose
- Automatic attendance tracking using face recognition
- Real-time person detection at church entrance
- Integration with church web application

## 🔧 Technical Setup

### Hardware (ESSL)
- Face recognition device/terminal
- Camera system
- Network connectivity

### Software Integration
- **Backend**: Node.js/Express API
- **Database**: MongoDB for user faces
- **Frontend**: Integrated into church website admin panel

## 📋 How It Works

### 1. Registration
1. User registers their face at church (admin panel)
2. Face data stored in database (encrypted)
3. Linked to member profile

### 2. Detection
1. Camera detects person at entrance
2. Face matched against registered faces
3. Attendance automatically marked

### 3. Reports
- Daily attendance logs
- Member-wise attendance
- Time-stamped entries

## 🔐 Data Security
- Face templates encrypted
- No raw images stored
- GDPR compliant design
