# Emmanuel Ministries Mobile App

A mobile app built for Emmanuel Ministries Hyderabad believers to stay connected with worship, sermons, announcements, attendance, and church services from their phone.

## 📱 Built For Believers

The app is designed to make everyday church interaction simple:
- sign in with WhatsApp OTP
- stay updated with events and sermons
- view worship timings and locations
- track worship attendance
- request parked vehicles
- give offerings
- stay connected with church communication

## ✨ Features Available

### 1. WhatsApp OTP Login
- login using mobile number
- OTP delivered through WhatsApp
- no password needed
- auto-login with stored token

### 2. Worship Attendance
- linked attendance for registered believers
- yearly worship attendance summary
- visual Sunday attendance timeline
- attendance linking for users whose records are not yet connected

### 3. Latest Sermons
- latest sermon videos from church YouTube content
- mobile-friendly sermon cards
- dedicated sermons page

### 4. Upcoming Events
- upcoming meetings and church events
- rich event cards with images and timing
- countdown-based event display
- full events page for more details

### 5. Worship Timings
- church worship timings and location details
- branch/location cards
- direct access to maps and contact details

### 6. Push Notifications
- app supports Firebase push notifications
- used for alerts, updates, and future believer communication features

### 7. Parking Request
- believers with active vehicle entry can request vehicle delivery
- status updates like:
  - in parking
  - requested
  - on the way
  - delivered
- volunteer and pickup details shown when relevant

### 8. Profile & Family Information
- believer profile view
- linked family details
- family members display with HOF highlighting
- volunteer information section when available

### 9. Prayer Request
- submit prayer request from the app
- uses stored believer details
- simple mobile-first form

### 10. Need Help
- believers can submit support/help requests
- requests are linked to the logged-in mobile user

### 11. Offerings
- offering categories
- preset and custom amount entry
- optional message with offering
- UPI details
- bank transfer details
- QR display
- payment gateway structure kept ready for future live integration

### 12. Social & Quick Connect
- WhatsApp channel
- Instagram
- Facebook
- quick actions from Home

## 🚀 In Progress / Planned

- announcement-driven notification system
- admin-managed content routing from notifications
- Songs Book with audio mode and lyrics mode
- PPT export for lyrics
- editable believer details
- HOF family picture update
- prayer schedule features
- live payment gateway integration

## 🛠 Technical Details

- **Framework**: React Native CLI
- **Language**: TypeScript
- **Backend**: Node.js / Express
- **Database**: MongoDB
- **Authentication**: WhatsApp OTP + JWT
- **Push**: Firebase
