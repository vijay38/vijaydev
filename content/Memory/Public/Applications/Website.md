# Emmanuel Ministries Website

A comprehensive Next.js website developed for Emmanuel Ministries Hyderabad.

## 🌐 Live Website
**URL**: [web.emmanuelministrieshyd.com](https://web.emmanuelministrieshyd.com)

- Weekly worship schedule
- Upcoming service timings
- Live service links
- Service recordings

### 📍 Locations & Contact
- All church locations
- Address details
- Maps integration
- Contact forms

### 📺 Latest Sermons
- YouTube video embeds
- Recent sermon uploads
- Preacher profiles
- Watch online

### 📅 Events Calendar
- Upcoming events

### 👥 Church Ministries
- Sunday School

- **New Comer Follow-up** - Manage new believer跟进

- **Get In Touch** - Handle contact form submissions
- **Meeting Requests** - Process meeting bookings
- **Chain Prayer** - Manage prayer chains
- **Phone Users** - Track phone call follow-ups
- **Call History** - Monitor interactions
- **Offerings** - Track giving and contributions
- **Events** - Manage church events
- **Gallery** - Church photo galleries
