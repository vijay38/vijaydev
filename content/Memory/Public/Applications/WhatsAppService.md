# Meta WhatsApp Service

WhatsApp-powered service for Emmanuel Ministries Hyderabad - members can get information and submit requests via WhatsApp!

## 📱 WhatsApp Number
**Message Hi to**: **+91 9440137776**

## ✨ What You Can Do

### 1️⃣ Get Service Timings
- Send "1" or "timings"
- Get weekly worship service times

### 2️⃣ Church Locations
- Send "2" or "location"
- Get all church locations with addresses

### 3️⃣ Request Parking
- Send "3" or "parking"
- Request your vehicle
- Get delivery updates

### 4️⃣ Prayer Request
- Send "4" or "prayer"
- Submit prayer request
- Get prayer support

### 5️⃣ Get in Touch
- Send "5" or "contact"
- Submit inquiry
- Church team will respond

### 6️⃣ Help
- Send "help" or "0"
- Get all available options

## 🔄 How It Works

1. User sends "Hi" to +91 9440137776
2. Bot responds with menu options (interactive buttons)
3. User selects option
4. Bot processes and provides info OR creates request
5. Request goes to admin dashboard for processing
6. User gets WhatsApp confirmation

## 📝 Example Flow

```
User: Hi
Bot: Welcome to Emmanuel Ministries! 🕇

Select an option:
🕐 Service Timings
📍 Locations
🚗 Parking
🙏 Prayer Request
📞 Get in Touch

Sunday Service - 9:00 AM
Tuesday Prayer - 7:00 PM

```

## 🛠 Technical Details
- **Platform**: WhatsApp Cloud API (Meta Business)
- **Backend**: Node.js/Express
- **Database**: MongoDB
- **Message Templates**: Interactive buttons
